# Roadmap

| Milestone | Required evidence before release |
|---|---|
| Application shell and capture | Qt GUI, D3D11 preview, desktop/window/game source validation |
| Streaming and recording | Decodable MKV and local RTMP(S) integration, encoder failure paths |
| Replay | Simultaneous outputs, saved replay integrity, hotkeys and bounded resources |
| Dynamic delay | Real relay increase/decrease tests, timestamps/A/V sync, reconnect behavior |
| Scene automation | Visual editor, priorities, process/focus/hotkey conditions, persistence |
| Plugins | Version checks, runtime loading, example action and documented compatibility |
| Packaging | Debug/Release builds, standalone portable smoke test, license/source inventory |
| Stable release | Failure-path regression suite, comparable performance data and known-limit review |

Do not turn placeholder controls or planned items into advertised completed features.
